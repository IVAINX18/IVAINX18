<details>
<summary><b>🛡️ ShadowNet Defender</b> — intelligent malware detection with deep learning</summary>
<br/>

Static malware detection for Windows PE binaries — a 2,381-d feature pipeline, DNN/ONNX inference, layered heuristics (YARA, PE, .NET, overlays) and local LLM explanations via Ollama.

<p>
  <a href="https://github.com/IVAINX18/Shadow-Net-Defender-Hybrid-Malware-Detection"><img src="https://img.shields.io/badge/Open_Repository-181717?style=flat-square&logo=github&logoColor=white" alt="Repository"/></a>

  <img src="https://img.shields.io/badge/Ollama-111111?style=flat-square" alt="Ollama"/>
</p>

| | |
| --- | --- |
| Stack | Python · PyTorch · ONNX Runtime · YARA · Ollama · Java |
| Scale | 2,381-dimensional feature pipeline; trained on large-scale datasets (EMBER, SOREL-20M) |
| Performance | 98.15% accuracy · 1.2% false positives · 0.65% false negatives (published IEEE results) |
| Security | Layered static analysis — PE parsing, YARA rules, .NET inspection, overlay detection — with human-readable local LLM explanations |
| Impact | Published at IEEE Xplore (Doc. 11214618) — intelligent malware detection system |
| Repository | https://github.com/IVAINX18/Shadow-Net-Defender-Hybrid-Malware-Detection |

A research-grade detection system that combines deep learning with classical static analysis: the neural model handles large-scale classification while layered heuristics catch structural anomalies, and every verdict is explained in plain language by a local LLM — no cloud dependency, no data leaving the machine.
